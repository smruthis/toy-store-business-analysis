# 🧸 Toy Store Sales Dashboard

## 📌 Project Overview

This project is an end-to-end Business Intelligence solution built using **SQL** and **Power BI** to analyze an e-commerce toy store dataset. The dashboard provides actionable insights into sales performance, product performance, customer behavior, website traffic, and marketing effectiveness.

The project demonstrates the complete analytics workflow—from SQL data analysis to interactive Power BI dashboard development.

---

## 🎯 Business Objective

The dashboard helps business stakeholders:

- Monitor overall business performance
- Analyze monthly sales and order trends
- Identify top-performing products
- Track website traffic and marketing performance
- Measure conversion rates
- Monitor refund amounts
- Support data-driven business decisions
